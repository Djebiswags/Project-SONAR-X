## 2026-03-31 - Multi-modal indicators & global hotkeys in Tkinter/CustomTkinter
**Learning:** For desktop telemetry HUDs and utility windows, color changes alone fail WCAG 1.4.1 for colorblind users. Combining color status changes with multi-modal visual indicators (such as 🟢 and 🚨) improves visual feedback clarity. In addition, global keyboard shortcuts (like Escape to dismiss utility windows) should be bound using `bind_all` on the root widget so they capture key events regardless of focus. Finally, recurring `.after()` calls in CustomTkinter must be tracked and cancelled via `after_cancel()` upon `destroy()` to prevent memory leaks and Tcl errors.
**Action:** Always combine status colors with distinct visual symbols, bind overlay dismissal hotkeys using `bind_all("<Escape>", ...)` on Tk root windows, and properly cancel scheduled `.after()` jobs in `destroy()`.
