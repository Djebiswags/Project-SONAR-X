## 2025-07-21 - [Multi-modal HUD Indicators & Escape Key Teardown]
**Learning:** For telemetry HUDs and utility windows built using CustomTkinter, adhering to WCAG 1.4.1 (Use of Color) requires combining color changes with multi-modal visual indicators (such as distinct emojis like 🟢 and 🚨) to assist colorblind users. Furthermore, binding the Escape key enhances keyboard accessibility. Crucially, when scheduling recurring telemetry updates via `.after()`, we must store the scheduled job ID and cancel it via `after_cancel()` in an overridden `destroy()` method to prevent memory leaks and threading/Tcl errors on teardown in headless/test environments.
**Action:** Always pair status colors with clear visual text/emoji signifiers, bind the Escape key to close utility dialogs, and robustly clean up all Tkinter `.after()` IDs inside `destroy()`.
