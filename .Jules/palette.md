## 2025-02-09 - [Multi-modal Indicators & Keyboard Shortcuts in Telemetry HUDs]
**Learning:** For telemetry HUDs and utility windows, adhering to WCAG 1.4.1 (Use of Color) is essential. Relying solely on green/red status colors is insufficient for colorblind users. Combining color changes with multi-modal visual indicators (such as distinct emojis like 🟢 and 🚨) improves comprehension significantly. Additionally, keyboard accessibility is critical for swift system utility overlays—always bind the Escape key globally via `bind_all` to close the topmost utility windows. When scheduling recurring telemetry or UI updates in CustomTkinter via `.after()`, it's vital to store the scheduled job ID and cancel it via `after_cancel()` in an overridden `destroy()` method to prevent memory leaks and threading/Tcl errors on teardown.
**Action:** When creating widget HUD overlays, always use a multi-modal visual indicator style, bind the Escape key globally to close/dismiss, and robustly clean up all recurring `.after()` job handles.
