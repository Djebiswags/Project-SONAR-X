## 2025-02-22 - Multi-Modal Status Indicators and Global Escape Binding in CustomTkinter
**Learning:** For telemetry HUDs in CustomTkinter, visual status updates relying solely on text color changes violate WCAG 1.4.1 (Use of Color). Combining visual indicators (e.g., status emojis `🟢`/`🚨`) with color changes ensures colorblind accessibility. Additionally, binding `<Escape>` globally using `self.bind_all("<Escape>", ...)` enables keyboard-only window dismissal regardless of active focus, and storing and canceling `.after()` timer IDs in `destroy()` avoids Tcl/Tk teardown errors.
**Action:** Always combine color coding with distinct textual/iconographic symbols for status changes, bind Escape key at the application root level with `bind_all`, and store `.after` job IDs for explicit cancellation in `destroy()`.
