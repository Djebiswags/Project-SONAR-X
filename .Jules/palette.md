## 2024-08-12 - CustomTkinter HUD Accessibility & Memory Management
**Learning:** For telemetry HUDs built with CustomTkinter/Tkinter, adhering to WCAG 1.4.1 requires multi-modal indicators (like 🟢 and 🚨) so that colorblind users can immediately distinguish normal vs warning states without relying purely on color differences. To ensure keyboard accessibility, global keys like Escape should be bound using `bind_all` rather than instance `bind` to catch keyboard focus regardless of focus state. Finally, calling `.after()` recursively can cause memory leaks or threading exceptions on window teardown if the task ID is not tracked and explicitly canceled via `after_cancel` inside an overridden `destroy()` method.
**Action:** Always combine color changes with symbolic indicators (emojis), bind global keys using `bind_all`, and track/cancel scheduled tkinter callbacks in `destroy()`.
