## 2025-02-14 - CustomTkinter Keyboard Accessibility and Resource Cleanup
**Learning:** For desktop telemetries and overlay utility HUDs, accessibility is vastly improved by binding global key shortcuts (such as the Escape key) using `bind_all` instead of instance-level `bind` so they are captured regardless of which sub-widget has focus. Additionally, conforming to WCAG 1.4.1 (use of color) requires augmenting purely colored indicator text with multi-modal markers (such as distinct status emojis). Finally, scheduling recurring GUI updates via `.after()` in CustomTkinter requires tracking the job ID and canceling it on destruction (`after_cancel`) to prevent background memory and thread leaks when the window is closed.
**Action:** Always bind window close/dismiss logic to Escape globally on any utility HUD or settings window using `bind_all("<Escape>", ...)` and store/cancel scheduling loops via `after_cancel()` upon window `destroy()`.
