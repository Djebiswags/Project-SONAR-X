## 2026-03-31 - [Multi-Modal Telemetry & Global Escape Key Dismissal in CustomTkinter]
**Learning:** For telemetry HUDs in CustomTkinter, visual indicators must combine color shifts (#00FFCC vs #FF3333) with distinct visual glyphs (🟢 for normal vs 🚨 for redline load) to comply with WCAG 1.4.1 (Use of Color). Furthermore, overlay utility windows should bind `<Escape>` globally using `bind_all` and safely cancel active `.after()` scheduled jobs on `destroy()` to prevent memory leaks or Tcl timer callback errors upon dismissal.
**Action:** When building secondary telemetry windows or utility HUDs in Tkinter/CustomTkinter, always provide multi-modal indicators (glyphs + color), bind `<Escape>` via `bind_all` for fast keyboard dismissal, and store/cancel scheduled timer jobs in `destroy()`.
