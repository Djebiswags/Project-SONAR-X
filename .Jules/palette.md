## 2025-07-24 - [WCAG 1.4.1 and Lifecycle Safety in CustomTkinter]
**Learning:** For desktop telemetries and HUD utility windows built on CustomTkinter, users with color blindness benefit immensely from multi-modal indicators (e.g. 🟢 and 🚨 symbols) alongside color shifts (green/red) to distinguish safe vs warning thresholds. Additionally, binding `<Escape>` to dismiss top-level utility windows ensures solid keyboard accessibility. Finally, always clean up periodic `.after()` callbacks via `.after_cancel()` in an overridden `.destroy()` method to prevent memory leaks and Tcl background errors on window closure.
**Action:** Always combine semantic symbols with color cues, bind `<Escape>` on lightweight dashboard panels, and override `.destroy()` to cancel any active `.after()` jobs.
