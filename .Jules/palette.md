## 2025-02-14 - [Adhere to WCAG 1.4.1 and prevent memory leaks in CustomTkinter widgets]
**Learning:** For telemetry HUDs and utility windows in CustomTkinter, it is critical to adhere to WCAG 1.4.1 (Use of Color) by combining color changes with multi-modal visual indicators (such as distinct emojis like 🟢 and 🚨) to assist colorblind users. Additionally, when scheduling recurring telemetry updates in CustomTkinter via `.after()`, storing the scheduled job ID and cancelling it via `after_cancel()` in an overridden `destroy()` method prevents memory leaks and threading/Tcl errors on teardown.
**Action:** Always pair color changes with visual cues/emojis for status indicators, bind keyboard Escape to close topmost widgets, and cancel any `.after()` scheduled jobs on teardown.
