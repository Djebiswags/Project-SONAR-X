## 2025-01-20 - Multi-modal Color Accessibility and Keyboard Hooks in CustomTkinter HUDs
**Learning:** For status-monitoring widgets and live telemetry dashboards, relying purely on color (e.g., green vs. red) violates WCAG 1.4.1 (Use of Color). This poses a severe accessibility challenge for colorblind users. To make it inclusive and accessible, color transitions must be paired with distinct non-color multi-modal indicators (such as `🟢` / `🚨` emojis). Additionally, user-friendly utility HUD windows should support immediate closure via standard keyboard bindings (like the `Escape` key) to ensure high keyboard-only navigability.
**Action:** Always combine telemetry value color-shifts with symbolic emojis/text changes and bind the `<Escape>` key to exit transient/utility windows.
