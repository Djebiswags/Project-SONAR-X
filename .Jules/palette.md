## 2025-02-15 - Multi-modal Telemetry Status & Escape Key Navigation in Tkinter
**Learning:** Color changes alone for status thresholds (e.g., green/red for high CPU/RAM) violate WCAG 1.4.1 (Use of Color) and are inaccessible to colorblind users. Combining color changes with distinct status emojis (🟢 Normal, 🚨 High Load, ⚠️ Warning) provides multi-modal status feedback. Additionally, utility overlay windows in desktop frameworks like CustomTkinter/Tkinter should always support the Escape key via global shortcut binding (`bind_all("<Escape>", ...)`) and cleanly cancel scheduled recurring jobs (`after_cancel`) during `destroy()` to prevent memory leaks and Tcl callback errors.
**Action:** When creating status badges or monitoring telemetry in desktop HUDs, always include accessible visual symbols alongside text/color changes and register teardown handlers for keyboard shortcuts and background update timers.
